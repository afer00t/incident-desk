# 90-second demo script

Record locally (`http://127.0.0.1:8777`, **LIVE · Clocked** visible in the header) or once the repo
is public, against a deployed instance. Keep the cursor visible; narrate in short sentences.

| Time | Action | Line |
|---|---|---|
| 0–6 | Open the app, point at the header | "Incident Desk. Every ticket passes Clocked before a human sees it." |
| 6–18 | Intake: wrong department laptop report with demo deadline | "PII is replaced first. Names, emails, assets — nothing raw is stored." |
| 18–26 | Show the Inbox row: `Critical`, owner Hardware | "Then Decide turns business impact into a typed severity, an owner, and a probability — not a keyword guess." |
| 26–40 | Answer tab, paste the false draft about the spooler | "The agent writes its answer. Grounding checks every claim. This one is ungrounded, and the weakest claim is the one the reviewer must fix." |
| 40–52 | Ingest a second payroll ticket (or load demo) | "Compare merges near-duplicates so payroll is not triaged twice." |
| 52–64 | KB tab, query "payroll portal ACCESS_DENIED" | "Rerank returns use, expand, skip with scores. The agent reads the useful passage, not ten lookalikes." |
| 64–78 | Script tab, paste `Set-MpPreference -DisableRealtimeMonitoring $true` | "Inspect reads the change request as data. This one disables endpoint protection, so it stops before anyone runs it." |
| 78–90 | Show credits counter, then the repo link | "Eight calls, one order: protect, decide, verify. Repo link is in the description." |

**Do not** claim a live Clocked response in the video if the recording uses MOCK mode; the header
shows the mode. Keep one take; the UI is deterministic (1280 px desktop, or 390 px phone layout).

Trim to 90 s: cut the answer tab walkthrough to 10 s and the KB tab to 8 s if the take runs long.
